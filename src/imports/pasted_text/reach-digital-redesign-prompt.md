# UI/UX REDESIGN PROMPT — REACH DIGITAL

Design and restructure the website for **Reach Digital** into a modern, professional **advertising-space discovery and booking platform**.

## 1. Product Context

Reach Digital connects businesses and advertisers with available advertising spaces.

The primary purpose of the website is NOT simply to present company information.

The website must help a visitor:

**Discover → Search → Filter → Explore → Compare → Select → Book an Advertising Space**

The entire UI/UX should therefore be designed around **advertising-space discovery and conversion**.

The website should feel like a combination of:

* A professional outdoor advertising company
* A modern marketplace
* A property/listing search platform
* A booking platform

The design should communicate:

**Trust + Visibility + Location + Availability + Convenience**

---

# 2. Primary UX Goal

When a new visitor lands on the homepage, they should immediately understand:

**"I can find and book advertising spaces here."**

The primary CTA should be:

**Find an Ad Space**

Secondary CTA:

**List Your Advertising Space**

Do NOT make the homepage primarily about company history, generic services, or long marketing text.

The advertising inventory should be the main focus.

# 19. Visual Design Direction

Use a premium, modern B2B visual language.

Style:

**Modern + Professional + Bold + Clean + Conversion-focused**

Avoid:

* Overly decorative designs
* Excessive animations
* Cluttered layouts
* Too many colours
* Generic corporate stock-photo layouts
* Huge blocks of text

Use:

* Large photography
* Strong typography
* Generous whitespace
* Rounded cards
* Subtle shadows
* Clear hierarchy
* High-quality icons
* Strong CTA buttons

The design should feel comparable to a modern marketplace such as a property or travel booking platform, but specifically designed for advertising inventory.

* Coordinates
* Advertising type
* Dimensions
* Images

* Availability
* Description

# 24. Final Design Objective

The redesigned Reach Digital website should feel like:

**"The easiest place to discover and book advertising spaces."**

The website should transform the current experience into a **search-first, inventory-driven, booking-focused platform**.

The most important user journey is:

**LAND → SEARCH → FILTER → DISCOVER → VIEW → COMPARE → BOOK → CONFIRM**

Design the entire experience around this journey.

Create the complete UI/UX for:

6. Booking flow
